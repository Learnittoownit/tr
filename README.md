# ✈️ Masra

> AI-powered travel planning for Saudi Arabia.

Masra is an intelligent iOS travel planning application developed during the **Apple Developer Academy**. It helps tourists and locals discover Saudi Arabia through personalized AI-generated itineraries or by manually planning their trips with complete flexibility.

By combining **LLM-powered recommendations** with **Google Maps integration**, Masra provides verified destinations, restaurants, cafés, attractions, and hidden gems—all in one seamless experience.

---

## ✨ Features

- 🤖 AI-generated personalized travel itineraries
- 🗺️ Manual trip planner for full customization
- 📍 Google Maps integration with verified locations
- ☕ Discover cafés, restaurants, shopping, and attractions
- 💰 Budget-based travel recommendations
- 📅 Multi-day itinerary planning
- 🧳 Personalized recommendations based on interests
- 📱 Modern SwiftUI user experience

---

## 🛠 Tech Stack

- Swift
- SwiftUI
- MVVM Architecture
- OpenAI API (LLM Integration)
- Google Maps API
- URLSession
- JSON
- Xcode

---

## 🏗 Architecture

Masra follows the **MVVM (Model–View–ViewModel)** architecture to separate presentation, business logic, and networking.

The AI planning engine communicates with an LLM through REST APIs, while Google Maps provides verified places and location information for a reliable travel experience.

## 🚀 Outcome
